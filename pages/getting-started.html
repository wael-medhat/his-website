Getting Started with HIS

Quick setup guide to get your Healthcare Information System up and running

Prerequisites

  • Node.js 16+ and npm
  • PHP 8.0+
  • MySQL 8.0+
  • Git

Installation Steps

1. Clone Repository

git clone https://github.com/his-system/his-project.git
cd his-project

2. Frontend Setup

cd frontend
npm install
npm run dev

3. Backend Setup

cd backend
php -S localhost:8000 -t public

4. Database Setup

mysql -u root -p < database/schema.sql

5. Environment Configuration

cp .env.example .env
# Edit .env with your configuration
