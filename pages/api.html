API Documentation

Complete reference for HIS System REST API

Authentication Endpoints

POST /api/auth/login

User login with email and password

curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@his.local","password":"password123"}'

Patient Endpoints

GET /api/patients

List all patients

curl -X GET http://localhost:8000/api/patients \
  -H "Authorization: Bearer YOUR_TOKEN"

Appointment Endpoints

GET /api/appointments

List all appointments

curl -X GET http://localhost:8000/api/appointments \
  -H "Authorization: Bearer YOUR_TOKEN"
Note: All API endpoints require JWT authentication. Include the token in the Authorization header.
