Deployment Guide

Deploy HIS System to production environments

Deployment Options

Docker Deployment

docker build -t his-system .
docker run -p 3000:3000 -p 8000:8000 his-system

Nginx Configuration

server {
    listen 80;
    server_name his-system.com;
    
    location / {
        proxy_pass http://localhost:3000;
    }
}

Apache Configuration

<VirtualHost *:80>
    ServerName his-system.com
    DocumentRoot /var/www/his-system
</VirtualHost>
Success! Your HIS System is ready for production deployment.
